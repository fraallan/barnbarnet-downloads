# Barnbarnet – nedladdningar

Här finns installationsfilerna (APK) för **Barnbarnet**, din digitala hjälpreda i vardagen,
för Android-telefoner.

**Ladda ner appen från [www.barnbarnet.se](https://www.barnbarnet.se)** – där finns också en
enkel guide för hur du installerar den.

Det här arkivet innehåller bara färdiga installationsfiler under
[Releases](../../releases). Appens källkod finns inte här.

## Kontrollera filen

Varje release anger filens SHA-256-kontrollsumma. Alla versioner av Barnbarnet är signerade
med samma certifikat:

```
SHA-256: 11:59:3A:E3:E3:29:35:49:66:6E:97:00:EE:52:36:ED:D1:06:88:68:49:95:EE:0B:18:06:80:27:F7:D2:67:47
```
